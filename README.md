# Markdown to Word Converter (Aura Edition)

A professional, high-performance Markdown to Word (.docx) converter built following the **JohnLC Aura Design Philosophy (ADP)** and the **JohnLC Development Framework v1.0 (AURA CORE)**.

## ✨ Features
- **Aura Design System:** Glass-morphism architecture with Midnight Obsidian tones and luminous gradients.
- **Real-time Rendering:** Instant Markdown preview powered by Marked.js.
- **Pure Backend:** Lightweight PHP conversion without heavy external dependencies.
- **Responsive & Accessible:** Fully compatible across all device sizes with a dedicated Dark Mode.
- **Production Ready:** No placeholders, secure input handling, and high performance.

## 🎨 Design Specification
- **Palette:** Midnight Obsidian (`#0f172a`), Luminous Indigo (`#3730A3`), and Cyan accents.
- **Typography:** Outfit (Headings) + Inter (Body) + Fira Code (Editor).
- **Glass Architecture:** 0.55 Opacity | 6px Blur | 24px Radius.
- **Motion:** 3-tier transition system (Fast, Normal, Bounce).

## 🚀 Installation & Setup
1. **Clone the repository:**
   ```bash
   git clone https://github.com/johnlcstudios-alt/markdowntoword.git
   ```
2. **Move to your local server root:**
   - For XAMPP: `C:\xampp\htdocs\markdowntoword`
   - For Linux: `/var/www/html/markdowntoword`
3. **Start your Apache server.**
4. **Access the app:**
   Navigate to `http://localhost/markdowntoword/` in your browser.

## 🛠️ Technologies Used
- **Frontend:** HTML5, CSS3 (Custom Properties), Vanilla JavaScript.
- **Backend:** Pure PHP.
- **Library:** Marked.js (Open Source).
